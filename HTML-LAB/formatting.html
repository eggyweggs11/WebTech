HTML TEXT FORMATTING

<br> bolds text for visual emphasis without implying extra importance
<strong> bolds text and indicates extra importance
<i> italicizes text to offset it for alternative voice,mood or technical terms
<em> italicizes text to add emphatic stress to change the sentence's meaing
<u> underlines text
<mark> highlights text with a yellow background
<small> reduces text size
<del> displays text with a strikethrough to mark deleted/removed content
<ins> underlines text to mark newly inserted content
<sub> renders text as a subscript lower than the main baseline
For example: H2O
<sup> renders text as a superscript higher than the main baseline
For example: E = mc2
